Interactive BPMN Website: Amazon Fulfillment Center

A web experience that maps how a package moves through an Amazon Fulfillment Center, from the inbound truck to the outbound carrier. Each step shows the role, its tools, its handoffs, and who is responsible.

01Problem

Fulfillment work is hard to picture from the outside.

Pain point

Text-heavy process docs

Written SOPs and org charts don't show how roles hand work to each other in real time.

Pain point

Feedback lacks context

Worker reviews mention pressure points, like rate, schedule and physical load, but readers can't see where those happen in the flow.

Pain point

Static BPMN is dense

Standard BPMN diagrams are accurate but intimidating for non-specialists and on small screens.

02Goals & Non-Goals

Goals

  • Explain the full FC workflow in under 3 minutes
  • Show role, tools, collaborators and RACI for each step
  • Make BPMN concepts (events, tasks, gateways) approachable
  • Give context for the Extern 308 worker-feedback analysis
  • Ship as one lightweight, shareable link

Non-goals

  • Real-time or internal Amazon operational data
  • User accounts, logins, or saved state
  • A full BPMN 2.0 editor
  • Representing any specific FC site exactly

06Non-Functional Requirements

Performance

Single file

One self-contained HTML file (~875 KB) with embedded WebP images and no build step.

Responsive

Desktop first, mobile friendly

Header collapses below 600px; flow scrolls by touch.

Hosting

Edge delivered

Cloudflare Workers static assets, HTTPS, custom domain with www.

Accessibility

Readable contrast

Light text on dark navy, orange for emphasis only, and keyboard-reachable controls.

Compliance

Educational use

Not affiliated with Amazon. Public information only; no personal data.

Maintainability

Data-driven steps

Steps are defined in one STEPS object, so adding a role is a data change.

09Risks & Assumptions

  • Accuracy: Role details come from public sources and may differ across FC sites.
  • Brand: Amazon naming and colors are used for education only, with a clear non-affiliation note.
  • File size: Embedded images keep it to one file but make it heavier; split assets if the site grows.
  • Sample limits: The linked feedback analysis uses 124 Glassdoor reviews and 8 YouTube videos, so read platform differences with care.
