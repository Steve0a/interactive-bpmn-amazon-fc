# PROMPT: ChatGPT Ideation Starter

## Purpose
Use these prompts in ChatGPT (or any AI) at the BEGINNING of a new project to explore ideas, define the problem, and gather your raw thinking before moving to structure.

---

## When To Use This
- When starting a brand new project
- When you have a vague idea and need to make it concrete
- Before jumping into Claude for structuring

---

## Ideation Prompt 1 — Big Picture Exploration

```
I want to build [DESCRIBE YOUR IDEA IN 1 SENTENCE].

Ask me 5 questions that will help me think through this more clearly. After I answer, summarize what I want to build in a structured paragraph.
```

---

## Ideation Prompt 2 — Components Breakdown

```
I want to create a system called: [NAME YOUR SYSTEM]

This system is for: [WHO IS IT FOR]
The main problem it solves: [WHAT PROBLEM]

What are the main components or sections this system would need? Give me a list with a short explanation for each.
```

---

## Ideation Prompt 3 — Steve's Personal Workflow Version

```
I am building a personal AI workflow system that I can use for my own projects and later sell or share on Gumroad or Medium.

Here is what I know so far:
- I use ChatGPT for big ideas
- I use Claude for structure and building files
- I want memory files to store what I know and learn
- I want templates I can reuse
- I want to document my SOPs (standard ways of doing things) in simple English

What else should I include? What am I missing? Give me 5-7 suggestions with reasons.
```

---

## Ideation Prompt 4 — SOP Discovery

```
Think about someone who works with AI tools every day to build projects.

What are the most common tasks or workflows they repeat again and again? List at least 8 of these recurring tasks and suggest a simple SOP (standard operating procedure) name for each.
```

---
